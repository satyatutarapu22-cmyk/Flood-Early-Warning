FLOOD EARLY WARNING SYSTEM - WEBSITE PROJECT

How to run:
1. Extract the ZIP file.
2. Open index.html in Google Chrome, Edge, or Firefox.
3. Click "Simulate Sensor Reading" to test Safe, Warning, and Danger states.

Project files:
- index.html  -> Website structure
- style.css   -> Design and responsive layout
- script.js   -> Water-level simulation and alert logic

Important:
This is a frontend educational/demo project. The sensor values are simulated.
For a real system, connect a water-level sensor (for example ESP32 + ultrasonic/water-level sensor) to a backend/API and use an official emergency notification service.
